# how it works

$ man imgconv

We could write a marketing page. We chose to write documentation. Read the source. Run the tool. It works the same in both places.

  • ▸ WebAssembly runs the codecs in your browser
  • ▸ COOP/COEP headers enable cross-origin isolation
  • ▸ ffmpeg.wasm handles every video and audio format
  • ▸ jsquash handles every image format
  • ▸ piexifjs strips metadata on the way out
~/imgconv — example.sh
1convert a folder of images
2$ imgconv --in ./photos --out ./web --to webp

# frequently asked

cat FAQ.md

Q: where does my file go? +
A: nowhere. it lives in the browser's memory until you close the tab. the conversion runs in webassembly, locally, in your process. we have no server. we couldn't see your file if we wanted to.
Q: is it really free? +
A: yes. no ads, no premium tier, no count of how many files you've converted. the source is MIT-licensed. if we ever add paid plans, you'll know first.
Q: why the terminal aesthetic? +
A: because the tool is for people who type. a terminal doesn't lie about what it is. neither do we.
Q: what formats are supported? +
A: images: jpg, png, webp, heic, gif. video: mp4, mov, webm, avi (re-encoded to mp4). audio: extracted to mp3. if it's not on the list, open an issue.
