Five ways to ship the
same eleven tools.

Five landing-page directions for the image converter. Each one solves the same problem — "I want to convert a file, fast" — through a completely different lens. Open the file you like, copy the patterns you like, ignore the rest.

01 DARK BENTO

Aurora

Linear / Vercel style. Deep near-blacks, ambient gradient blobs, indigo accent, asymmetric bento grid, mouse-tracking spotlights. The default if you want to look like a serious developer tool.

02 LIGHT EDITORIAL

Editorial

Newspaper aesthetic. Off-white paper, Fraunces serif headlines, hairline rules, alphabetical tool list with a sidebar of stats. Quiet, considered, forever.

03 BOLD PLAYFUL

Brutalist

Loud, proud, and unapologetic. Thick black borders, hard 6-10px shadows, lime/pink/blue palette, marquee banners, sticker accents. The opposite of "subtle".

04 SOFT FRIENDLY

Glassmorphism

Pastel gradient backdrop, frosted glass cards, floating coloured blobs, soft drop shadows, gentle floating animation. Friendly and inviting without being saccharine.

05 DARK DEV-TOOL

Terminal

For people who type. Monospace everything, green-on-black, scanlines and noise overlay, $ prompts, code blocks, an ASCII art header, live latency counter. Documentation as marketing.
