HOW IT WORKS

Three soft steps.

Pick a tool

Eleven of them. Each one does one thing, gently.

Drop your file

It stays in your browser. We promise.

Download the result

In a few seconds. Then we forget it ever happened.

Built with care.
Zero servers.

Drift is a small, open-source project. Every conversion happens in your browser via WebAssembly. Your files are never uploaded, never logged, never seen by us. The whole thing is a few hundred kilobytes.
